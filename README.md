# Data Analytics Project

## Overview

This project demonstrates an end-to-end data analytics workflow, starting from dataset loading and exploration to data cleaning, SQL analysis, dashboard creation, reporting, and presentation.

The project focuses on extracting meaningful insights from raw data using Python, PostgreSQL, and Power BI. The final outcomes include an interactive dashboard, analytical report, and presentation created using Gamma.

---

## Dataset

The dataset used in this project contains structured data related to business operations and performance analysis.

### Data Processing Tasks:
- Loaded the dataset using Python
- Explored dataset structure and data patterns
- Identified missing values and inconsistencies
- Cleaned and transformed data for analysis
- Prepared the dataset for SQL analysis and visualization

---

## Tools & Technologies

| Tool | Purpose |
|------|---------|
| Python | Data loading, cleaning, and Exploratory Data Analysis (EDA) |
| Pandas | Data manipulation and preprocessing |
| Matplotlib / Seaborn | Data visualization during EDA |
| PostgreSQL | Data storage and SQL-based analysis |
| SQL | Querying and extracting insights |
| Power BI | Interactive dashboard development |
| Gamma | Creating project presentation |
| Microsoft Word / Documentation Tools | Analytical report creation |

---

## Project Workflow

### 1. Data Loading
- Imported the dataset into Python environment
- Checked data types, columns, and dataset size
- Reviewed initial records for understanding

### 2. Exploratory Data Analysis (EDA)
Performed analysis to understand:
- Data distribution
- Trends and patterns
- Relationships between variables
- Outliers and unusual observations

### 3. Data Cleaning
Steps performed:
- Handled missing values
- Removed duplicate records
- Corrected data formats
- Created required calculated fields
- Prepared clean data for further analysis

### 4. SQL Analysis using PostgreSQL
- Imported cleaned dataset into PostgreSQL
- Created SQL queries to answer business questions
- Used operations such as:
  - Filtering
  - Aggregations
  - Joins
  - Group By
  - Window Functions

### 5. Power BI Dashboard
Built an interactive dashboard containing:
- Key Performance Indicators (KPIs)
- Charts and visual trends
- Filters for better analysis
- Business insights from the dataset

### 6. Report Creation
Created a detailed analytical report covering:
- Problem statement
- Data preparation process
- Analysis approach
- Key findings
- Recommendations

### 7. Presentation Development
Created a professional project presentation using Gamma covering:
- Project overview
- Methodology
- Insights
- Dashboard highlights
- Final conclusions

## How to Run

### Step 1: Clone Repository

```bash
git clone <repository-link>
```

### Step 2: Install Required Python Libraries

```bash
pip install pandas matplotlib seaborn sqlalchemy psycopg2
```

### Step 3: Run Python Notebook
- Open the Jupyter Notebook
- Execute data loading, EDA, and cleaning steps

### Step 4: Setup PostgreSQL
- Create database and tables
- Import cleaned dataset
- Run SQL queries from the SQL folder

### Step 5: Open Power BI Dashboard
- Open the `.pbix` file
- Refresh data connection
- Explore dashboard insights

This project showcases practical data analytics skills including data cleaning, exploratory analysis, SQL querying, dashboard development, and business reporting. It demonstrates the complete workflow followed by data analysts to transform raw data into meaningful insights.
